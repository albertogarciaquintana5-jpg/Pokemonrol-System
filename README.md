## 📖 Descripción

**Pokemonrol-System** es un sistema web completo de gestión de rol de Pokémon diseñado para facilitar partidas de rol con mecánicas de Pokémon. El sistema incluye autenticación de jugadores, gestión completa de Pokémon, sistema de combate con dados, inventario de objetos, y un poderoso panel de administración para el Game Master.

Este proyecto permite a los jugadores:
- 🎯 Gestionar sus equipos de Pokémon
- 📦 Organizar su caja de almacenamiento
- 🎒 Administrar su inventario de objetos
- 📘 Completar su Pokédex
- ⚔️ Participar en combates con sistema de dados (d100)
- 💰 Comprar objetos en la tienda

Y a los Game Masters:
- 👥 Gestionar todos los jugadores y sus datos
- 🎁 Dar Pokémon y objetos a jugadores
- 🔧 Modificar estadísticas de Pokémon
- 💵 Administrar el dinero de los jugadores
- 📊 Ver estadísticas completas del juego

## 🚀 Instalación y Configuración

### 📋 Requisitos Previos

```bash
✅ PHP 7.4 o superior
✅ MySQL 5.7 o superior
✅ Apache o Nginx
✅ Servidor web local (XAMPP/WAMP/LAMP recomendado)
```

### 📥 Pasos de Instalación

#### 1️⃣ Clonar el Repositorio

```bash
git clone https://github.com/albertogarciaquintana5-jpg/Pokemonrol-System.git
cd Pokemonrol-System
```

#### 2️⃣ Configurar Base de Datos

**Opción A: Usando phpMyAdmin**
1. Abre phpMyAdmin
2. Crea una nueva base de datos llamada `rol`
3. Importa el archivo `migrations/004-create-fresh-db.sql`

**Opción B: Desde línea de comandos**

```bash
# Crear la base de datos
mysql -u root -p -e "CREATE DATABASE rol CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# Importar la estructura y datos iniciales
mysql -u root -p rol < migrations/004-create-fresh-db.sql

# (Opcional) Configurar usuario administrador
mysql -u root -p rol < migrations/011-setup-master-user.sql
```

#### 3️⃣ Configurar Conexión a Base de Datos

Edita el archivo `db.php` con tus credenciales:

```php
$DB_HOST = 'localhost';      // Tu host de MySQL
$DB_USER = 'root';           // Tu usuario de MySQL
$DB_PASS = '';               // Tu contraseña de MySQL
$DB_NAME = 'rol';            // Nombre de la base de datos
```

#### 4️⃣ Copiar a Servidor Web

**Para XAMPP (Windows/Mac/Linux):**
```bash
# Copiar la carpeta al directorio htdocs
cp -r Pokemonrol-System C:/xampp/htdocs/
```

**Para WAMP (Windows):**
```bash
# Copiar la carpeta al directorio www
cp -r Pokemonrol-System C:/wamp64/www/
```

**Para LAMP (Linux):**
```bash
# Copiar a /var/www/html
sudo cp -r Pokemonrol-System /var/www/html/
sudo chown -R www-data:www-data /var/www/html/Pokemonrol-System
```

#### 5️⃣ Iniciar el Servidor

1. Inicia Apache y MySQL desde tu panel de control (XAMPP/WAMP)
2. Abre tu navegador y accede a:
   ```
   http://localhost/Pokemonrol-System
   ```

## 🎮 Uso

### 👤 Para Jugadores

#### Registro y Login
1. Accede a `http://localhost/Pokemonrol-System`
2. Si no tienes cuenta, haz clic en "Registrarse"
3. Completa el formulario de registro
4. Inicia sesión con tus credenciales

#### Dashboard del Jugador
Una vez dentro, tendrás acceso a:

- **🎒 Inventario** - Ver y usar tus objetos
  - Usa pociones para curar Pokémon
  - Revivir Pokémon debilitados
  - Enviar objetos a otros jugadores

- **📦 Caja de Pokémon** - Gestiona tu colección completa
  - Ver todos tus Pokémon
  - Equipar Pokémon a tu equipo
  - Ver estadísticas detalladas (HP, nivel, experiencia)

- **⚔️ Equipo** - Tu equipo activo (máximo 6 Pokémon)
  - Ver tu equipo de combate
  - Desequipar Pokémon a la caja
  - Ver estado de salud

- **📘 Pokédex** - Registra tu progreso
  - Ver Pokémon vistos
  - Ver Pokémon capturados
  - Estadísticas de encuentros

- **🛒 Tienda** - Compra objetos
  - Compra pociones, revivir, etc.
  - Gestiona tu dinero

- **🎲 Sistema de Dados** - Tiradas d100
  - Realizar tiradas de dados
  - Ver historial de tiradas
  - Limpiar historial

### 👑 Para Game Masters

#### Acceso al Panel de Administración
1. Inicia sesión con una cuenta de administrador (usuario ID 67)
2. En el dashboard, haz clic en **"Panel Master"**
3. Accederás al panel de control completo

#### Funcionalidades del Panel Master

**👥 Gestión de Jugadores**
- Ver lista completa de todos los jugadores
- Buscar jugador específico
- Ver detalles completos (equipo, caja, inventario)

**🎁 Dar Pokémon**
- Selecciona un jugador
- Elige la especie de Pokémon
- Define nivel, apodo y estadísticas
- El Pokémon aparece en su caja

**🎁 Dar Objetos**
- Selecciona un jugador
- Elige el objeto
- Define la cantidad
- Se añade a su inventario

**💵 Gestión de Dinero**
- Modifica el balance de cualquier jugador
- Útil para recompensas o penalizaciones

**🔧 Editar Pokémon**
- Ver cualquier Pokémon del sistema
- Modificar HP actual
- Cambiar nivel y experiencia
- Actualizar estado (envenenado, paralizado, etc.)
- Curar instantáneamente

## 🔧 API Endpoints

### 🎮 Endpoints para Jugadores

| Método | Endpoint | Descripción | Parámetros |
|--------|----------|-------------|------------|
| `GET` | `/api/get_inventory.php` | Obtener inventario del jugador | - |
| `POST` | `/api/use_item.php` | Usar un objeto | `item_id`, `box_id` (opcional) |
| `GET` | `/api/get_box.php` | Obtener caja de Pokémon | - |
| `GET` | `/api/get_team.php` | Obtener equipo activo | - |
| `POST` | `/api/move_pokemon.php` | Equipar/desequipar Pokémon | `action`, `box_id`, `slot` |
| `GET` | `/api/get_pokedex.php` | Obtener Pokédex | - |
| `POST` | `/api/mark_pokedex.php` | Marcar Pokémon en Pokédex | `species_id`, `visto`, `capturado` |
| `POST` | `/api/d100_roll.php` | Realizar tirada d100 | - |
| `GET` | `/api/d100_history.php` | Historial de tiradas | - |
| `POST` | `/api/buy_item.php` | Comprar objeto | `item_id` |
| `POST` | `/api/send_item.php` | Enviar objeto a otro jugador | `item_id`, `to_email` |
| `POST` | `/api/learn_move.php` | Aprender movimiento | `pokemon_id`, `move_id` |

### 👑 Endpoints de Administración

> ⚠️ **Requieren autenticación como Game Master (usuario ID 67)**

| Método | Endpoint | Descripción | Parámetros |
|--------|----------|-------------|------------|
| `GET` | `/api/admin_get_player.php` | Obtener datos completos de un jugador | `user_id` |
| `GET` | `/api/admin_get_pokemon.php` | Obtener datos de un Pokémon | `pokemon_id` |
| `POST` | `/api/admin_update_pokemon.php` | Actualizar estadísticas de Pokémon | `pokemon_id`, `nivel`, `hp`, `exp`, `status` |
| `POST` | `/api/admin_give_pokemon.php` | Dar Pokémon a un jugador | `user_id`, `species_id`, `apodo`, `nivel`, `hp` |
| `POST` | `/api/admin_give_item.php` | Dar objetos a un jugador | `user_id`, `item_id`, `cantidad` |
| `POST` | `/api/admin_remove_item.php` | Eliminar objeto de inventario | `user_id`, `item_id` |
| `POST` | `/api/admin_update_money.php` | Actualizar dinero de jugador | `user_id`, `money` |
| `POST` | `/api/admin_heal_pokemon.php` | Curar Pokémon completamente | `pokemon_id` |
| `POST` | `/api/admin_teach_move.php` | Enseñar movimiento a Pokémon | `pokemon_id`, `move_id` |

### 📝 Formato de Respuesta

Todos los endpoints devuelven JSON:

**Éxito:**
```json
{
  "success": true,
  "data": { ... }
}
```

**Error:**
```json
{
  "success": false,
  "error": "Mensaje de error descriptivo"
}
```

### 🔐 Autenticación

Todos los endpoints requieren una sesión activa de PHP. La cookie `PHPSESSID` se envía automáticamente desde el navegador.

Para probar endpoints desde herramientas como curl:

```bash
# 1. Inicia sesión y copia el PHPSESSID
# 2. Usa la cookie en tus peticiones
curl -b "PHPSESSID=tu_session_id_aqui" \
  -H "Content-Type: application/json" \
  -d '{"item_id":1}' \
  http://localhost/Pokemonrol-System/api/use_item.php
```
